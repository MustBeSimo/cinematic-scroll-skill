# The 10× Narrative — Cinematic Scroll

The canonical story. It supersedes the Claude-only framing. Everything — landing, README,
launch, pitch — ladders up to this. The point is portability: **this is a skill, not a plugin.**

---

## Logline

> **Cinematic Scroll is a portable craft skill that gives any coding agent the taste to build cinematic, scroll-driven websites.**

Claude, Cursor, Hermes, OpenClaw — whatever you run, whatever comes next. The craft travels with you.

---

## The thesis (why this is 10×, not a nicer template)

AI agents can already write code. What almost none of them have is **taste** — the art direction that separates a generic centered-hero page from something that feels *filmed*. Taste is the last thing anyone expected to package. It's judgment, not syntax: pacing, depth, restraint, when *not* to move.

Cinematic Scroll packages exactly that. It encodes a creative director's judgment — film grammar, a 5-phase pipeline, taste guardrails, a performance budget — into a skill any agent can load. You're not installing a component library. **You're giving your agent an eye.**

And because it's a *skill* — a portable spec, not a vendor plugin — it isn't chained to one IDE. It rides with you across every agent. Your craft shouldn't be locked to your tool.

That's the 10×: not "a better scroll library," but **the first skill that transfers taste, to any agent, for free.**

## Category coinage

Position it as **the first craft skill** — a new class of agent skill that transfers *aesthetic judgment*, not just automation. Most skills do chores (run tests, file tickets). A craft skill does taste. Owning that phrase ("craft skill") gives the project a category to lead instead of a crowded shelf to compete on.
