One skill · many worlds

Brutalist, quiet-luxury, Gen-Z pop, noir, organic, retro — each is a depth-0.75 subject layer that parallaxes under HTML titles while the background morphs between color-worlds.

Two altitudes, one skill

Ask for a section. Or ask for a site.

Mode A

A scroll artifact

One self-contained .html or .tsx section — no build, no keys. Pinned chapters, 5–7 depth layers, 3D camera, mask/stagger title reveals, reduced-motion-safe.

Mode B

A full release site

A complete Next.js project scaffolded from tested templates, with an optional fal.ai pipeline that art-directs your chapter imagery. Stunning on first paint, zero AI setup required.

The flagship example

“Classic Touch — The Renaissance Edition.”

Eight chapters, manifest-driven, in a single build-free HTML file — pinned parallax, scroll-spy rail, gold↔oxblood atmosphere morph, 3D hero tilt. It mirrors the production React/Next.js edition at w230.net/reinassence.
