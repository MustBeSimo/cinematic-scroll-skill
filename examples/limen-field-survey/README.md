# LIMEN — Field Survey

An original cinematic example website for the `cinematic-scroll` skill.

## What it demonstrates

- Premium generated hero imagery used as a real web asset, not a video backdrop.
- Two overlapping image layers with a scroll-scrubbed CSS `clip-path` scan.
- Fixed scientific HUD panels and a target reticle connected to the specimen.
- Five selectable colonies with live data, macro crops, and optical repositioning.
- Procedural Web Audio ambience behind an explicit user-controlled sound toggle.
- A complete website after the hero: signal catalogue, field protocol, and closing chapter.
- Mobile release of the pinned scene into a touch-safe stacked layout.
- `prefers-reduced-motion` fallback with all content visible.

## Originality boundary

The example is an original composition inspired by the broad grammar of cinematic scientific interfaces. It does not reproduce another creator's subject names, copy, layout measurements, assets, code, or branded interface.

## Files

- `index.html` — self-contained page logic and styling.
- `assets/limen-specimen.png` — generated exobotanical hero plate.
